# Apsara & Co.

Interactive prototype site for an Indian-American Ayurvedic skincare and makeup brand. Visual direction follows a **modern luxe heritage** moodboard: deep forest green, midnight, beetroot magenta, and antique gold—rich texture without costume excess.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- shadcn/ui primitives

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4321](http://127.0.0.1:4321).

## What’s on the page

- Lotus/arch brand mark and wordmark intro
- Full-bleed parallax hero
- Filterable product collection with hover sheen
- Ritual steps on misted forest backdrop
- Interactive dosha quiz
- Botanical ingredient explorer (arch image frame)
- Brand story + lookbook collage
- Waitlist capture (client-side demo)

## Brand notes

Palette and motifs (lotus arch, jali overlay, silk/stone atmosphere) are drawn from the project moodboard in `assets/` and `public/images/moodboard.jpg`.
